PS5 Wake

Wake your PlayStation 5 with Wake-on-LAN using an ESP32-C6 board. Version –.

Install or update the firmware

  1. Use Chrome or Edge on a computer.
  2. Connect the ESP32-C6 board with a USB data cable.
  3. Click the button and choose the board's serial port.
Your browser does not support Web Serial. Use Chrome or Edge on a computer. The installer needs a secure (HTTPS) page.

When updating, answer No to “Erase device” to keep your settings; a first installation should erase it. If the port does not appear, hold BOOT while plugging in the cable.

After installing

  1. A new device starts the setup panel network by itself (purple LED). Later, hold BOOT for 5–20 seconds and release – the LED turns red.
  2. Connect to the Wi-Fi network PS5-WAKE-xxxx, password ps5wol-setup.
  3. Open https://192.168.4.1 (or https://ps5-wake-xxxx.local) and accept the certificate warning – the ESP32 uses its own certificate.
