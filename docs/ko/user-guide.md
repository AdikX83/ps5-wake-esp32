# PS5 Wake – 사용 설명서

PS5 Wake는 Wake-on-LAN 패킷을 받거나 보드의 버튼을 누르면 PlayStation 5를 켜 주는 작은 ESP32-C6 보드입니다. 블루투스를 통해 페어링된 DualSense 컨트롤러처럼 동작하여 PS 버튼을 누른 것과 같은 효과를 냅니다. 휴식 모드와 완전히 꺼진 상태 모두에서 작동합니다.

## 필요한 것

- PS5 Wake가 설치된 ESP32-C6 보드(테스트 완료: ESP32-C6-DevKitM-1), 아무 USB 충전기로나 전원 공급 가능.
- PS5와 이미 페어링된 DualSense(또는 DualSense Edge) 컨트롤러.
- 컴퓨터와 **데이터 전송용** USB 케이블 – 펌웨어 설치와 컨트롤러 주소 읽기에 한 번만 필요합니다.
- 2.4GHz Wi-Fi 네트워크.

## 1. 펌웨어 설치

Chrome 또는 Edge에서 웹 설치 프로그램(프로젝트 README에 링크 있음)을 열고 USB 케이블로 보드를 연결한 뒤 **Install or update**을 클릭합니다. 새 기기는 **보라색**으로 켜집니다. 설정 패널 네트워크를 자동으로 시작합니다.

## 2. 설정 패널 열기

1. **BOOT** 버튼을 5~20초 동안 누르고 있다가 놓습니다. LED가 **빨간색**으로 바뀝니다. 새 기기는 패널이 이미 켜져 있습니다(보라색 LED). 이 단계는 건너뛰세요.
2. 컨트롤러를 연결할 컴퓨터에서 Wi-Fi 네트워크 `PS5-WAKE-xxxx`에 연결합니다(비밀번호 `ps5wol-setup`).
3. 브라우저에서 **`https://192.168.4.1`**(또는 `https://ps5-wake-xxxx.local`)를 엽니다. ESP32가 자체 인증서를 사용하므로 브라우저가 연결이 비공개가 아니라고 경고합니다. **고급 → 계속**을 선택하세요(이름은 브라우저마다 다릅니다).
4. 페이지 상단에서 언어를 선택합니다.

## 3. 컨트롤러 주소 읽기

1. USB 케이블로 DualSense를 컴퓨터에 연결합니다.
2. 패널의 **Bluetooth** 섹션에서 주소 읽기 프로그램을 다운로드합니다:
   - **Windows:** `ps5-wake-reader.cmd` – 두 번 클릭해 실행합니다. Windows가 알 수 없는 게시자에 대해 경고하면 **추가 정보 → 실행**을 선택합니다.
   - **macOS:** `pip3 install hidapi` → `python3 ps5_wake_reader.py`
   - **Linux:** `sudo python3 ps5_wake_reader.py`
3. 읽기 프로그램이 본체와 컨트롤러의 블루투스 주소를 표시하고 **설정 코드**(`PS5WAKE:…`)를 클립보드에 복사합니다. 이를 **주소 판독기의 설정 코드** 필드에 붙여 넣으면 두 주소가 모두 입력됩니다.

주소는 컨트롤러를 본체와 다시 페어링할 때만 바뀝니다.

## 4. 설정 완료

1. **검색**으로 Wi-Fi 네트워크를 선택하고 비밀번호를 입력한 뒤 국가를 선택합니다.
2. **패널 네트워크의 새 비밀번호**(8자 이상)를 입력합니다. 기본 비밀번호는 공개되어 있으므로 필수입니다.
3. **저장 후 다시 시작**을 클릭합니다. 패널이 닫히고, 연결 중에는 LED가 **파란색**으로 깜박이며 준비가 끝나면 **초록색**으로 켜집니다.

## 5. Wake-on-LAN 설정

- Wake-on-LAN 앱(또는 라우터의 WoL 페이지)에서 패널에 표시된 **이 ESP32의 MAC 주소**, UDP 포트 **9**, 네트워크의 **브로드캐스트 주소**(예: `192.168.1.255`)를 사용합니다.
- 라우터에서 ESP32에 고정 IP 주소를 예약합니다.
- 앱이나 라우터가 이미 **PS5 자체의 네트워크 MAC 주소**를 사용한다면 **PS5 본체의 MAC 주소에도 반응** 필드에 입력할 수 있습니다. 그러면 ESP32가 그 주소에도 반응합니다. 메시 네트워크(예: ASUS AiMesh)에서는 이런 패킷이 ESP32에 도달하지 않을 수 있으니, 그런 경우 ESP32의 MAC 주소로 WoL을 보내세요.

## 일상적인 사용

- **본체 상태:** 패널 상단 전원 아이콘의 점은 PS5가 켜져 있으면 초록색, 휴식 모드에서는 주황색, 꺼져 있거나 연결할 수 없으면 빨간색입니다(회색: 아직 찾지 못함). 휴식 모드는 본체가 휴식 모드에서도 인터넷에 연결된 상태일 때만 감지됩니다.
- **PS5 깨우기:** Wake-on-LAN 패킷을 보내거나 **BOOT**를 짧게 누릅니다. LED가 흰색으로 한 번 깜박이고, 시도 중에는 청록색으로 깜박인 뒤 **초록색 3회**(본체 응답) 또는 **빨간색 3회**(응답 없음) 깜박입니다.
- 시도 사이에는 최소 30초 간격이 있으며, 무시된 요청은 주황색으로 한 번 깜박입니다.

## BOOT 버튼

| 누르는 시간 | 누르는 동안 LED | 결과 |
|---|---|---|
| 1초 미만 | – | PS5 깨우기 |
| 1~5초 | 흰색 | 없음(취소) |
| 5~20초 후 놓기 | 빨간색(15초부터 깜박임) | 설정 패널 열기 |
| 20초 | 보라색, 빠르게 깜박임 | 모든 설정 삭제 후 재시작 |

전원을 연결할 때 BOOT를 누르고 있으면 Wi-Fi와 블루투스 없이 안전 모드로 시작합니다(노란색 LED).

## LED 색상

| 색상 | 동작 | 의미 |
|---|---|---|
| 보라색 | 켜짐 | 설정 안 됨 – 설정 패널 켜짐 |
| 파란색 | 천천히 깜박임 | Wi-Fi 연결 중 |
| 주황색 | 천천히 깜박임 | Wi-Fi는 설정되었지만 30초 이상 연결되지 않음 |
| 초록색(어둡게) | 켜짐 | 준비 완료(패널에서 끌 수 있음) |
| 빨간색 | 켜짐 | 설정 패널 켜짐 |
| 노란색 | 켜짐 | 안전 모드 |
| 흰색 | 1회 깜박임 | Wake-on-LAN 수신 또는 BOOT 누름 |
| 청록색 | 빠르게 깜박임 | 깨우기 시도 중 |
| 초록색 | 3회 깜박임 | 본체가 응답함 |
| 빨간색 | 3회 깜박임 | 본체가 응답하지 않음 |
| 주황색 | 1회 깜박임 | 요청 무시됨(시도 중이거나 30초 대기 중) |

## 설정 패널

- 패널과 패널 네트워크는 저장 후, **변경 없이 닫기** 후, 또는 10분 동안 아무 작업이 없으면 꺼집니다. **연장**로 시간을 늘릴 수 있습니다.
- **LED 완전히 끄기**: 색상, 깜박임, 번쩍임을 전혀 표시하지 않습니다. BOOT를 누르고 있는 동안에만 누른 시간을 LED로 표시합니다.
- **기기 이름(선택)**: 예: Living room. 패널 주소(`living-room.local`), Home Assistant, 페이지 제목에 사용됩니다. 기기가 여러 대일 때 유용합니다.
- **홈 네트워크에서 접근**: 기본적으로 켜져 있습니다. 이 페이지는 홈 네트워크의 `<ESP32 IP>` 및 `ps5-wake-xxxx.local`에서 항상 사용할 수 있습니다. 패널 비밀번호로 로그인하세요(변경하지 않았다면 사용자 이름은 admin). 패널 Wi-Fi 네트워크는 시작되지 않으며, 열려면 BOOT를 5초간 누르세요.
- **암호화된 연결(HTTPS)**: 권장. ESP32가 자체 인증서를 만들기 때문에 처음 접속할 때 브라우저가 연결이 비공개가 아니라고 경고합니다. 아래 지문을 비교한 후 계속하세요. HTTPS를 사용하지 않으면 비밀번호와 설정이 암호화되지 않은 채 네트워크로 전송됩니다. 인증서는 만료 전에 자동으로 갱신됩니다(ESP32가 인터넷에서 시간을 가져옴). **새 인증서**으로 즉시 새 인증서를 만들 수 있습니다.
- **지금 PS5 깨우기**로 패널에서 바로 깨우기를 테스트할 수 있습니다.

## 문제 해결

- **LED가 주황색으로 깜박임:** Wi-Fi 비밀번호 오류, 5GHz 전용 네트워크 또는 약한 신호입니다. 패널을 열어 Wi-Fi 설정을 확인하고 ESP32를 라우터 가까이로 옮기세요. ESP32는 2분 동안 연결이 끊기면 자동으로 재시작합니다.
- **Wake-on-LAN을 보내도 아무 반응이 없음(흰색 깜박임 없음):** 패킷이 ESP32에 도달하지 않습니다. ESP32의 MAC 주소, 브로드캐스트 주소, 포트 9를 사용하고 ESP32가 게스트 네트워크에 있지 않은지 확인하세요.
- **시도 후 빨간색 깜박임:** 블루투스 주소를 확인하고(컨트롤러를 다시 페어링했다면 다시 읽으세요) ESP32를 본체 가까이로 옮기세요.
- **읽기 프로그램이 컨트롤러를 찾지 못함:** 데이터 전송용 케이블(충전 전용 아님)을 사용하고 컨트롤러를 컴퓨터에 직접 연결하세요.
- **브라우저가 인증서 경고를 표시함:** 정상입니다. 패널은 ESP32 자체 인증서로 암호화됩니다. 페이지로 계속 진행하세요. 패널에 인증서 지문이 표시됩니다.
