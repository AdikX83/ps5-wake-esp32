# PS5 Wake – 用户指南

PS5 Wake 是一块小型 ESP32-C6 开发板，在收到网络唤醒（Wake-on-LAN）数据包或按下板上按键时开启你的 PlayStation 5。它通过蓝牙模拟你已配对的 DualSense 手柄——就像按下 PS 键一样。支持从待机模式和完全关机状态唤醒主机。

## 所需物品

- 一块装有 PS5 Wake 的 ESP32-C6 开发板（已测试：ESP32-C6-DevKitM-1），可由任意 USB 充电器供电。
- 一个已与 PS5 配对的 DualSense（或 DualSense Edge）手柄。
- 一台电脑和一根支持**数据传输**的 USB 线——仅需一次，用于安装固件和读取手柄地址。
- 一个 2.4 GHz Wi-Fi 网络。

## 1. 安装固件

在 Chrome 或 Edge 中打开网页安装程序（链接见项目 README），用 USB 线连接开发板并点击 **Install**。新设备的指示灯显示为**紫色**。它会自动开启设置面板网络。

## 2. 打开设置面板

1. 按住 **BOOT** 键 5–20 秒后松开。指示灯变为**红色**。新设备的面板已自动开启（紫色指示灯）——可跳过此步骤。
2. 在要连接手柄的电脑上连接 Wi-Fi 网络 `PS5-WAKE-xxxx`，密码 `ps5wol-setup`。
3. 在浏览器中打开 **`https://192.168.4.1`**（或 `https://ps5-wake-xxxx.local`）。由于 ESP32 使用自己的证书，浏览器会提示连接不是私密连接——请选择**高级 → 继续前往**（名称因浏览器而异）。
4. 在页面顶部选择语言。

## 3. 读取手柄地址

1. 用 USB 线将 DualSense 连接到电脑。
2. 在面板的 **蓝牙** 部分下载地址读取程序：
   - **Windows:** `ps5-wake-reader.cmd` – 双击运行。如果 Windows 提示未知发布者，请选择 **更多信息 → 仍要运行**。
   - **macOS:** `pip3 install hidapi` → `python3 ps5_wake_reader.py`
   - **Linux:** `sudo python3 ps5_wake_reader.py`
3. 读取程序会显示主机和手柄的蓝牙地址，并将**设置代码**（`PS5WAKE:…`）复制到剪贴板。将其粘贴到 **来自地址读取工具的设置代码** 字段中——两个地址会自动填写。

只有在手柄与主机重新配对后，地址才会改变。

## 4. 完成设置

1. 点击 **扫描** 选择 Wi-Fi 网络，输入密码并选择国家/地区。
2. 输入**面板网络的新密码**（至少 8 个字符）。由于默认密码是公开的，此项为必填。
3. 点击 **保存并重启**。面板关闭，连接时指示灯**蓝色**闪烁，一切就绪后显示**绿色**。

## 5. 设置网络唤醒

- 在网络唤醒应用（或路由器的 WoL 页面）中使用面板显示的 **此 ESP32 的 MAC 地址**、UDP 端口 **9** 和网络的**广播地址**（例如 `192.168.1.255`）。
- 在路由器中为 ESP32 保留固定 IP 地址。
- 如果你的应用或路由器已经使用 **PS5 本身的网络 MAC 地址**，可以将其填入 **同时响应 PS5 自身的 MAC 地址** 字段——ESP32 也会对其作出响应。在 Mesh 网络（如 ASUS AiMesh）中，这类数据包可能无法到达 ESP32；此时请将 WoL 发送到 ESP32 的 MAC 地址。

## 日常使用

- **主机状态：**面板顶部电源图标上的圆点在 PS5 开启时为绿色，待机模式时为橙色，关闭或无法访问时为红色（灰色：尚未发现）。只有当主机在待机模式下保持联网时才能检测到待机状态。
- **唤醒 PS5：**发送网络唤醒数据包或短按 **BOOT**。指示灯白色闪一次，尝试期间青色闪烁，随后**绿色闪 3 次**（主机已响应）或**红色闪 3 次**（无响应）。
- 两次尝试之间至少间隔 30 秒；被忽略的请求会橙色闪一次。

## BOOT 键

| 按住时间 | 按住时的指示灯 | 结果 |
|---|---|---|
| 少于 1 秒 | – | 唤醒 PS5 |
| 1–5 秒 | 白色 | 无操作（取消） |
| 5–20 秒后松开 | 红色（15 秒起闪烁） | 打开设置面板 |
| 20 秒 | 紫色快速闪烁 | 清除所有设置并重启 |

接通电源时按住 BOOT 将启动不带 Wi-Fi 和蓝牙的安全模式（黄色指示灯）。

## 指示灯颜色

| 颜色 | 状态 | 含义 |
|---|---|---|
| 紫色 | 常亮 | 未设置——设置面板已开启 |
| 蓝色 | 慢闪 | 正在连接 Wi-Fi |
| 橙色 | 慢闪 | 已设置 Wi-Fi，但超过 30 秒未连接 |
| 绿色（暗） | 常亮 | 就绪（可在面板中关闭） |
| 红色 | 常亮 | 设置面板已开启 |
| 黄色 | 常亮 | 安全模式 |
| 白色 | 闪 1 次 | 收到网络唤醒或按下 BOOT |
| 青色 | 快闪 | 正在尝试唤醒 |
| 绿色 | 闪 3 次 | 主机已响应 |
| 红色 | 闪 3 次 | 主机未响应 |
| 橙色 | 闪 1 次 | 请求被忽略（正在尝试或 30 秒间隔内） |

## 设置面板

- 保存后、点击 **不保存并关闭面板** 后或 10 分钟无操作后，面板及其网络会关闭。**延长** 可延长时间。
- **完全关闭指示灯**: 不显示任何颜色、闪烁或闪光。只有在按住 BOOT 时，指示灯仍会显示按住时间。
- **设备名称（可选）**: 例如 Living room。用于面板地址（`living-room.local`）、Home Assistant 和页面标题——多台设备时很有用。
- **从家庭网络访问**: 默认开启。 此页面将在家庭网络中通过 `<ESP32 的 IP>` 和 `ps5-wake-xxxx.local` 持续可用——使用面板密码登录（用户名为 admin，除非已修改）。不会开启面板 Wi-Fi 网络；如需开启，请按住 BOOT 5 秒。
- **加密连接（HTTPS）**: 推荐开启。ESP32 会自行创建证书，因此首次访问时浏览器会提示连接不是私密连接——请核对下方的指纹后继续。不使用 HTTPS 时，密码和设置会在网络中以未加密方式传输。 证书会在到期前自动续期（ESP32 从互联网获取时间）；**生成新证书** 可立即生成新证书。
- **立即唤醒 PS5** 可直接在面板中测试唤醒。

## 故障排除

- **指示灯橙色闪烁：**Wi-Fi 密码错误、仅有 5 GHz 网络或信号弱。打开面板检查 Wi-Fi 设置，并将 ESP32 移近路由器。ESP32 离线 2 分钟后会自动重启。
- **发送网络唤醒后无反应（无白色闪烁）：**数据包未到达 ESP32。请使用 ESP32 的 MAC 地址、广播地址和端口 9；确认 ESP32 不在访客网络中。
- **尝试后红色闪烁：**检查蓝牙地址（手柄重新配对后需重新读取），并将 ESP32 移近主机。
- **读取程序找不到手柄：**请使用数据线（而非仅充电线），并将手柄直接连接到电脑。
- **浏览器提示证书警告：**这是正常的——面板使用 ESP32 自己的证书加密。继续访问页面即可；面板中会显示证书指纹。
