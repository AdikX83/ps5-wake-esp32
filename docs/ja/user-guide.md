# PS5 Wake – ユーザーガイド

PS5 Wake は小型の ESP32-C6 ボードで、Wake-on-LAN パケットを受信したとき、またはボタンを押したときに PlayStation 5 の電源を入れます。Bluetooth でペアリング済みの DualSense コントローラーとして振る舞い、PS ボタンを押したのと同じ動作をします。レストモードからも、完全に電源が切れた状態からも起動できます。

## 必要なもの

- PS5 Wake を書き込んだ ESP32-C6 ボード（動作確認済み：ESP32-C6-DevKitM-1）。任意の USB 充電器から給電できます。
- PS5 とペアリング済みの DualSense（または DualSense Edge）コントローラー。
- パソコンと**データ通信対応**の USB ケーブル（ファームウェアのインストールとコントローラーのアドレス読み取りに 1 回だけ使用）。
- 2.4 GHz の Wi-Fi ネットワーク。

## 1. ファームウェアのインストール

Chrome または Edge で Web インストーラー（プロジェクトの README にリンクあり）を開き、USB ケーブルでボードを接続して **Install or update** をクリックします。新しいデバイスは**紫色**に点灯します。設定パネル用のネットワークを自動的に起動します。

## 2. 設定パネルを開く

1. **BOOT** ボタンを 5～20 秒押し続けてから離します。LED が**赤色**に点灯します。新しいデバイスではパネルがすでにオンになっています（紫の LED）。この手順は不要です。
2. コントローラーを接続するパソコンで Wi-Fi ネットワーク `PS5-WAKE-xxxx` に接続します（パスワード `ps5wol-setup`）。
3. ブラウザーで **`https://192.168.4.1`**（または `https://ps5-wake-xxxx.local`）を開きます。ESP32 は独自の証明書を使うため、ブラウザーが「この接続ではプライバシーが保護されません」と警告します。**詳細設定 → アクセスする**を選択してください（表示はブラウザーにより異なります）。
4. ページ上部で言語を選択します。

## 3. コントローラーのアドレスを読み取る

1. USB ケーブルで DualSense をパソコンに接続します。
2. パネルの **Bluetooth** セクションからアドレス読み取りツールをダウンロードします：
   - **Windows:** `ps5-wake-reader.cmd` – ダブルクリックで実行します。Windows が不明な発行元について警告した場合は **詳細情報 → 実行** を選択します。
   - **macOS:** `pip3 install hidapi` → `python3 ps5_wake_reader.py`
   - **Linux:** `sudo python3 ps5_wake_reader.py`
3. 読み取りツールが本体とコントローラーの Bluetooth アドレスを表示し、**設定コード**（`PS5WAKE:…`）をクリップボードにコピーします。**アドレス読み取りツールの設定コード** 欄に貼り付けると、両方のアドレスが入力されます。

アドレスが変わるのは、コントローラーを本体と再ペアリングした場合だけです。

## 4. 設定を完了する

1. **スキャン** で Wi-Fi ネットワークを選び、パスワードを入力して国を選択します。
2. **パネル用ネットワークの新しいパスワード**（8 文字以上）を入力します。初期パスワードは公開されているため、入力は必須です。
3. **保存して再起動** をクリックします。パネルが閉じ、接続中は LED が**青色**に点滅し、準備ができると**緑色**に点灯します。

## 5. Wake-on-LAN を設定する

- Wake-on-LAN アプリ（またはルーターの WoL ページ）で、パネルに表示される **この ESP32 の MAC アドレス**、UDP ポート **9**、ネットワークの**ブロードキャストアドレス**（例：`192.168.1.255`）を使用します。
- ルーターで ESP32 に固定 IP アドレスを割り当てます。
- アプリやルーターがすでに **PS5 本体のネットワーク MAC アドレス**を使っている場合は、**PS5 本体の MAC アドレスにも反応する** 欄に入力できます。ESP32 はそのアドレスにも反応します。メッシュネットワーク（例：ASUS AiMesh）ではこのようなパケットが ESP32 に届かないことがあるため、その場合は ESP32 の MAC アドレスに WoL を送ってください。

## 日常の使い方

- **本体の状態：** パネル上部の電源アイコンの点は、PS5 がオンのときは緑、レストモードではオレンジ、オフまたは応答がないときは赤になります（グレー：まだ検出されていません）。レストモードは、本体がレストモード中もインターネットに接続している場合のみ検出されます。
- **PS5 を起動する：** Wake-on-LAN パケットを送るか、**BOOT** を短く押します。LED が白く 1 回光り、試行中は水色に点滅し、その後**緑色に 3 回**（本体が応答）または**赤色に 3 回**（応答なし）光ります。
- 試行の間隔は 30 秒以上です。無視されたリクエストはオレンジ色の 1 回点滅で示されます。

## BOOT ボタン

| 押している時間 | 押している間の LED | 結果 |
|---|---|---|
| 1 秒未満 | – | PS5 を起動 |
| 1～5 秒 | 白 | 何もしない（キャンセル） |
| 5～20 秒で離す | 赤（15 秒から点滅） | 設定パネルを開く |
| 20 秒 | 紫・高速点滅 | すべての設定を消去して再起動 |

電源を接続するときに BOOT を押し続けると、Wi-Fi と Bluetooth を使わないセーフモードで起動します（黄色の LED）。

## LED の色

| 色 | 動作 | 意味 |
|---|---|---|
| 紫 | 点灯 | 未設定 – 設定パネルがオン |
| 青 | ゆっくり点滅 | Wi-Fi に接続中 |
| オレンジ | ゆっくり点滅 | Wi-Fi は設定済みだが 30 秒以上未接続 |
| 緑（暗め） | 点灯 | 準備完了（パネルで消灯可能） |
| 赤 | 点灯 | 設定パネルがオン |
| 黄 | 点灯 | セーフモード |
| 白 | 1 回点滅 | Wake-on-LAN を受信、または BOOT が押された |
| 水色 | 高速点滅 | 起動を試行中 |
| 緑 | 3 回点滅 | 本体が応答した |
| 赤 | 3 回点滅 | 本体が応答しなかった |
| オレンジ | 1 回点滅 | リクエストを無視（試行中または 30 秒の待機中） |

## 設定パネル

- パネルとそのネットワークは、保存後、**変更せずに閉じる** の後、または操作がないまま 10 分経過するとオフになります。**延長** で時間を延長できます。
- **LED を完全にオフにする**: 色、点滅、フラッシュを一切表示しません。BOOT を押している間だけ、押している時間を LED で表示します。
- **デバイス名（任意）**: 例: Living room。パネルのアドレス（`living-room.local`）、Home Assistant、ページのタイトルに使われます。複数台使う場合に便利です。
- **ホームネットワークからのアクセス**: 初期設定でオンです。 このページはホームネットワークの `<ESP32 の IP>` と `ps5-wake-xxxx.local` で常に利用できます。パネルのパスワードでログインしてください（変更していなければユーザー名は admin）。パネル用 Wi-Fi ネットワークは起動しません。開くには BOOT を 5 秒押してください。
- **暗号化接続（HTTPS）**: 推奨。ESP32 は独自の証明書を作成するため、初回アクセス時にブラウザーが「この接続ではプライバシーが保護されません」と警告します。下のフィンガープリントを確認して続行してください。HTTPS を使わない場合、パスワードと設定は暗号化されずにネットワークを流れます。 証明書は期限切れ前に自動更新されます（ESP32 はインターネットから時刻を取得します）。**新しい証明書** ですぐに新しい証明書を作成できます。
- **今すぐ PS5 を起動** でパネルから直接起動をテストできます。

## トラブルシューティング

- **LED がオレンジ色に点滅：** Wi-Fi パスワードの誤り、5 GHz のみのネットワーク、または電波が弱い可能性があります。パネルを開いて Wi-Fi 設定を確認し、ESP32 をルーターに近づけてください。2 分間オフラインが続くと ESP32 は自動的に再起動します。
- **Wake-on-LAN を送っても何も起きない（白い点滅がない）：** パケットが ESP32 に届いていません。ESP32 の MAC アドレス、ブロードキャストアドレス、ポート 9 を使い、ESP32 がゲストネットワークにないことを確認してください。
- **試行後に赤く点滅：** Bluetooth アドレスを確認し（コントローラーを再ペアリングした場合は読み直してください）、ESP32 を本体に近づけてください。
- **読み取りツールがコントローラーを見つけない：** データ通信対応のケーブル（充電専用ではないもの）を使い、コントローラーをパソコンに直接接続してください。
- **ブラウザーが証明書について警告する：** これは正常です。パネルは ESP32 独自の証明書で暗号化されています。ページに進んでください。パネルに証明書のフィンガープリントが表示されます。
